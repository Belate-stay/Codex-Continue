# Close to system tray

**Goal:** Closing the window hides it to the Windows notification area while detection and armed continuation keep running. Double-clicking the icon or choosing Open restores the same window. Only the tray Exit command explicitly quits.

**Approach:** Use the Windows desktop framework's `NotifyIcon` and context menu, with the existing application icon and localized Open/Exit labels. Cancel ordinary window closing and hide the window. Keep actual shutdown cleanup in `Closed`, dispose tray resources there, and allow Windows session shutdown to close normally. Guard first-load initialization so restoration cannot reset the current screen or duplicate timers. Keep the existing minimize button behavior.
