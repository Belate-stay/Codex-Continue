# Tray menu implementation plan

**Goal:** Show exactly four tray commands in this order: Open Codex-Continue, Settings, Run/Stop, Exit. Use a red triangle for Run and a red square for Stop. Keep the existing single-instance, close-to-tray and continuation lifecycle.

**Design:** Reuse Windows Forms NotifyIcon for the notification icon and a native WPF ContextMenu for the popup. A local resource dictionary supplies a 12 DIP rounded card, 8 DIP rounded hover faces, 40 DIP rows, 14 DIP existing UI font and theme brushes. All labels align to one icon column, with restrained 120–150 ms ease-out feedback and reduced-motion support. No new package or setting. The red run-state symbol remains semantic red across accents and appearances.

**Behavior:** Open restores the same window. Settings restores it directly to the inline settings mode, including from startup or release details, without stopping an armed task. Run/Stop calls the existing main run handler. Incomplete commands disable Run and show the existing formal hint. State refreshes when the command or armed state changes; Stop remains available while hidden. The popup takes focus for keyboard navigation and closes on selection, Escape or outside click. Exit performs existing shutdown cleanup.
