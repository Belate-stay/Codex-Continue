# Title logo

`OpenAI.svg` is the unmodified OpenAI Blossom asset from the official OpenAI Agents SDK repository:
https://github.com/openai/openai-agents-python/blob/main/docs/assets/logo.svg

The title bar uses the same path as a native WPF `DrawingImage` in `MainWindow.xaml`, with nonzero fill and the neutral text brush for light/dark appearance. It renders as vector geometry in the existing 20 DIP slot. The SVG is embedded for source provenance; it is not rasterized for display.

The README logo (`docs/logo-light.svg` / `docs/logo-dark.svg`) is derived from the same path: light variant uses dark ink for light backgrounds, dark variant keeps the original white fill.

The OpenAI mark belongs to OpenAI. Brand guidance: https://openai.com/brand/
